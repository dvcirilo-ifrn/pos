1. Qual a diferença entre *access token* e *refresh token*? Por que o *access token* costuma ter validade curta?
1. O que é manipulação da DOM? Cite 3 métodos ou propriedades usados para selecionar ou alterar elementos de uma página.

1. O que é JSX? Em que ele se diferencia do HTML comum?
1. Qual a diferença entre *props* e *state* em um componente React?
1. O que é *prop drilling*? Como a Context API resolve esse problema?
